Subject: Pre-BFCM data: 19% of Shopify storefronts in a random sample double-send GA4 page views

Hi Paul,

I scanned a random sample of Shopify storefronts in the Majestic Million, 386 stores, for tracking problems. On a single page load:

- 73 (19%) send GA4 the same page view twice
- 31 (8%) fire the Meta pixel twice
- 64 (17%) send data to two or more GA4 properties
- 23 (6%) still load Universal Analytics, which Google shut off in 2023

A panel of 192 DTC brands I picked by hand gave the same GA4 and UA rates within a point, so it isn't a quirk of how I picked stores.

None of this shows up as an error in the dashboard, so merchants head into Black Friday reading these numbers as true.

I think it makes a useful item before BFCM: the numbers plus a two-minute check any merchant can run in Chrome. You'd have it first. The full report goes up on ecomloop.com the day you run it, or in two weeks if you pass.
